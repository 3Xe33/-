# منصة الحوسبة السحابية الذكية
إعداد: عمار ياسر الفهيد — إدارة أنظمة شبكات

## التشغيل
افتح `index.html` في متصفح حديث، أو ارفع كامل محتويات المجلد إلى GitHub Pages.

## ملفات الموقع
- `index.html`: صفحات ومحتوى المنصة.
- `media/intro-video.mp4`: الفيديو التعريفي المضاف والمضمّن في قسم الوسائط.

## ملاحظة حول بقية الوسائط
قسم البودكاست ما زال ينتظر ملف التسجيل الصوتي النهائي.
