01 / KNOWLEDGE BASE

البحث المعرفي

محتوى علمي منظم يشرح المفاهيم الأساسية للحوسبة السحابية وتطبيقاتها.

ما الحوسبة السحابية؟

الحوسبة السحابية هي نموذج يتيح الوصول عبر الشبكة، عند الطلب، إلى مجموعة مشتركة من موارد الحوسبة القابلة للتهيئة مثل الخوادم والتخزين والشبكات والتطبيقات، مع إمكانية توفيرها أو تحريرها بسرعة وبجهد إداري محدود. وبدل شراء البنية التحتية وتشغيلها محليًا، تستطيع المؤسسة استخدام الموارد كخدمات حسب الحاجة.

الفكرة الأساسية: موارد تقنية مرنة عند الطلب، مع قياس الاستخدام وإدارته.

المرونة والتوسع

زيادة أو تقليل الموارد حسب تغير الطلب، دون الحاجة إلى شراء خوادم جديدة لكل توسع.

خفض الاستثمار الأولي

تقليل الحاجة إلى شراء الأجهزة وتجهيز مراكز البيانات وصيانتها داخليًا، مع ضرورة مراقبة تكاليف الاستخدام.

سرعة الابتكار

إتاحة بيئات تطوير واختبار وخدمات جاهزة تساعد الفرق على إطلاق الحلول بسرعة أكبر.

ملاحظة علمية: الحوسبة السحابية لا تعني أن الأمن مضمون تلقائيًا أو أن التكلفة أقل دائمًا؛ فالنتيجة تعتمد على التصميم والحوكمة وإدارة الهوية والتكاليف.
02 / DEPLOYMENT & SERVICE MODELS

أنواع السحابة ونماذج الخدمات

أولًا: نماذج النشر

PUBLIC CLOUD

السحابة العامة

موارد يقدمها مزود خارجي عبر الإنترنت وتُشارك بنيتها التحتية بين عملاء متعددين مع عزل منطقي لكل عميل.

PRIVATE CLOUD

السحابة الخاصة

بيئة مخصصة لمؤسسة واحدة، تمنحها تحكمًا أكبر في الموارد والسياسات، لكنها قد تتطلب مسؤولية تشغيلية وتكلفة أعلى.

HYBRID CLOUD

السحابة الهجينة

دمج بيئة خاصة أو محلية مع خدمات سحابة عامة، مع تكامل واتصال منظم بين البيئتين.

MULTICLOUD

السحابة المتعددة

استخدام خدمات من مزودين سحابيين عامين أو أكثر، لأسباب مثل تنويع الخدمات أو المرونة أو متطلبات العمل.

السياق السعودي

توضح هيئة الاتصالات والفضاء والتقنية وجود مزودي خدمات سحابية ومراكز بيانات داخل المملكة، كما تنشر قياسات لأداء الوصول إلى الخدمات السحابية. ويُعد موقع مركز البيانات وزمن الاستجابة والامتثال عوامل مهمة عند اختيار المزود.

لا تُقارن الشركات بالشعارات فقط؛ قارن الخدمات الفعلية، مواقع الاستضافة، التوافر، الأمن، الدعم، والتكلفة.

05 / SAUDI DIGITAL CAREERS

الفرص الوظيفية والمهارات في السعودية

Cloud Administrator

إدارة الحسابات والموارد السحابية والمراقبة والنسخ الاحتياطي والتحديثات.

Cloud Network Engineer

تصميم الشبكات الافتراضية وVPN وDNS والجدران النارية والربط بين البيئات.

Cloud Security Engineer

إدارة الهوية والصلاحيات والتشفير والسياسات ومراقبة التهديدات.

Cloud Architect

تصميم الحلول السحابية وموازنة الأداء والتكلفة والأمان والتوافر.

DevOps / Platform Engineer

الأتمتة وخطوط CI/CD والحاويات والبنية التحتية ككود.

Cloud Support Specialist

تشخيص الأعطال ومتابعة الحوادث ودعم المستخدمين والخدمات.

مهارات مقترحة للمتدرب في إدارة أنظمة الشبكات

أساسيات TCP/IP وDNS وDHCP وVPN، Linux وWindows Server، الافتراضية، الشبكات السحابية، IAM، أساسيات الأمن السيبراني، PowerShell أو Python، المراقبة، النسخ الاحتياطي، وقراءة التكاليف.

شهادات يمكن دراستها تدريجيًا: AWS Certified Cloud Practitioner، Microsoft Azure Fundamentals (AZ-900)، Google Cloud Digital Leader، ثم شهادات إدارية أو معمارية متقدمة بحسب المسار.

المذيع الأول: أهلًا بكم! اليوم بنتكلم عن الحوسبة السحابية بطريقة بسيطة.

المذيع الثاني: تخيل أن ملفاتك وبرامجك تقدر توصل لها من أي مكان، من غير ما تكون محفوظة كلها على جهازك.

المذيع الأول: هذا جزء من فكرة السحابة: خوادم ومراكز بيانات تقدم لك موارد عبر الإنترنت عند الحاجة.

المذيع الثاني: والتخزين السحابي يعني حفظ الصور والملفات والنسخ الاحتياطية على خوادم بعيدة، مع إمكانية الوصول لها من أجهزتك.

المذيع الأول: ومن أمثلته Google Drive وOneDrive. أما خدمات الحوسبة السحابية فتشمل أيضًا تشغيل التطبيقات وقواعد البيانات والخوادم.

المذيع الثاني: عندنا ثلاثة نماذج مشهورة: IaaS للبنية التحتية، وPaaS للمنصات، وSaaS للبرامج الجاهزة.

المذيع الأول: ومن أهم الفوائد المرونة وسرعة التوسع وتقليل شراء الأجهزة مقدمًا، لكن لازم ننتبه للأمان وإدارة الصلاحيات والتكلفة.

المذيع الثاني: صحيح، اختَر مزودًا موثوقًا، فعّل المصادقة متعددة العوامل، واحتفظ بنسخ احتياطية مهمة.

المذيع الأول: الخلاصة: السحابة تخلي التقنية أقرب وأسهل في الوصول، إذا استخدمناها بتخطيط وأمان.
